Projects


      

        
Quadruped Robot & Locomotion Sim

        
A 12-servo, 3D-printable quadruped designed in Fusion 360, exported to URDF and simulated in MuJoCo. A trot gait controller makes it stand, walk and turn in place. The hardware mode (servos through a PCA9685 board on a Raspberry Pi) is written and tested against a fake servo board, but waits for the first build. It walks perfectly in simulation, where friction always behaves.

        
Python, MuJoCo, Fusion 360, Raspberry Pi Repo

        
      


      

        
Rate-Adaptive Pacemaker Firmware

        
Pacemaker firmware modelled in Simulink and Stateflow for an NXP FRDM-K64F board, with Embedded Coder generating the C that runs on it. The team model paces in AOO, VOO, AAI and VVI modes. My part was the rate-adaptive modes (AOOR, VOOR, AAIR, VVIR): they read the board's FXOS8700 accelerometer and raise the pacing rate with activity, tuned by threshold, reaction and recovery times.

        
Simulink, Stateflow, Embedded Coder, NXP FRDM-K64F Repo

        
        
      


      

        
Ontario Nuclear Grid Impact Analysis

        
What happens to Ontario's grid when a reactor goes offline? 11.8 million rows of hourly IESO data in DuckDB, SQL that finds 206 outages of a day or longer, and an interactive dashboard that shows who picks up the slack. Mostly gas and fewer exports. Outage hours line up with prices about $4/MWh higher and about 145 more tonnes of CO2 an hour. Reactor behaviour is next.

        
SQL (DuckDB), Python, Streamlit, IESO data Live app Repo

        
        
      


      

        
Vision-Guided 2-DOF Robotic Arm

        
Built in 12 hours, about as long as SolidWorks takes to open. A real-time OpenCV hand-tracking pipeline streams coordinate deltas over UDP to an ESP32, which turns them into smooth stepper motor pulses.

        
OpenCV, ESP32, C++, UDP

        
      


      

        
Globe Ghost — iOS GPS Simulator

        
Sets an iPhone's actual GPS location, not just its IP address like a VPN does, for testing location-aware apps. Includes a live map, scripted routes and a geofence tester.

        
Python, pymobiledevice3, OpenStreetMap Repo

        
      


      

        
Résumé Sync Pipeline

        
Updating my résumé got tedious, so I spent far too long automating it. Every Sunday a script checks my repos, an AI agent proposes source-backed edits, and GitHub Actions makes sure it still compiles on one page. I review everything before merging. The repo's private, mostly so nobody watches me reword the same bullet eleven times.

        
Python, GitHub Actions, LaTeX, Claude Code

        
      


      

        
WheelSafe Storage

        
An ergonomic, weatherproof wheelchair storage module designed for a client with spina bifida. The 0.4 kg carbon-fiber-reinforced structure reached a 3.25:1 load-to-weight ratio. Placed top 3 of 200+ teams at the McMaster Design Showcase.

        
Autodesk Inventor, client prototyping, carbon fiber Demo Presentation

        
      


      

        
Double Wishbone Suspension (Concept)

        
Proof-of-concept double wishbone geometry in SolidWorks for McMaster Chem-E-Car's 2026–2027 season. Nothing is built yet: the point was to work out the kinematics and see how the linkage could control dynamic camber to keep a 500 mL sloshing payload stable over a 33 m run.

        
SolidWorks, kinematics, vehicle dynamics
